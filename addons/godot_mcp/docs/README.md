# Godot MCP 文档

安装、启动和常用流程见 [插件使用指南](../README_zh-CN.md)。当前插件为 0.6.2 / 协议 2，默认展示 25 个工具，完整注册 63 项。

| 文档 | 用途 |
| --- | --- |
| [工具参考手册](tool_reference_zh-CN.md) | 各工具的参数、结果、错误处理与调用示例 |
| [机器可读工具契约](tool_catalog.json) | 从当前注册表生成的完整输入输出 Schema |
| [Output 面板](output_control.md) | 显示、筛选、搜索、折叠、文本分页和清空语义 |
| [编辑器一致性约束](editor_consistency.md) | 原生命令处理层、Undo、资源引用、人工操作共存及限制 |
| [职责边界](tool_scope.md) | MCP 会话操作与文件工具、无头流程的分工 |
| [定制引擎维护](engine_patches.md) | 配套引擎接口、构建、验证、同步与升级方式 |

本目录仅维护当前有效、可持续更新的说明与契约。阶段计划、开发流水、临时审查清单、测试输出、性能测量和构建产物不放在这里，也不随插件部署。验证脚本保留在 tests/；每次运行的报告输出到系统临时目录或 CI 制品目录。
